# Phase 1 — Static HTML/CSS

This folder contains the Phase 1 deliverable: a responsive, static landing page for SyncRoom.

## Contents

- `index.html` — Semantic markup, Create Room and Join Room sections.
- `css/styles.css` — CSS custom properties, glassmorphism panels, gradient background, responsive layout.

## How to view

Open `index.html` in a browser (e.g. drag into Chrome, or use a simple static server):

```bash
# From repo root, optional:
npx serve phase1-static
# Then open http://localhost:3000
```

No JavaScript is required for Phase 1; buttons and links are placeholders. The React app in `client/` will replace this as the main frontend while keeping the same visual design.
